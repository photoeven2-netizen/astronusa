LEGAL & DATA SAFETY

Kebijakan Privasi AstroNusa

Terakhir diperbarui: 24 Oktober 2026
Komitmen Privasi: AstroNusa dirancang dengan filosofi Privacy-First. Kami tidak melacak, tidak menjual, dan tidak menyalahgunakan data pribadi pengguna.

1. Data yang Disimpan di Perangkat Anda (Lokal)

Untuk menghitung peta kelahiran, Human Design, Weton/Primbon, dan numerologi, aplikasi menyimpan data berikut secara lokal di memori perangkat Anda:

  • Nama Panggilan/Nama Lengkap: Digunakan untuk perhitungan numerologi Pythagorean.
  • Tanggal dan Waktu Kelahiran: Digunakan untuk menghitung posisi transit benda langit dan zodiak.
  • Kota/Lokasi Kelahiran: Digunakan untuk memperoleh koordinat garis lintang dan bujur serta zona waktu (WIB, WITA, WIT).

Seluruh data di atas disimpan secara terenkripsi menggunakan modul penyimpanan aman perangkat (Android Keystore / Secure Storage). Data ini tidak pernah diunggah ke server kami untuk disimpan.

2. Pemrosesan Fitur AI Coach

Saat Anda memilih untuk menggunakan fitur interaktif "AI Coach", aplikasi akan mengirimkan data anonim yang telah diproses terlebih dahulu:

  • Hanya ringkasan posisi astrologi (seperti tanda Matahari, Bulan, Ascendant) dan angka numerologi yang dikirimkan.
  • Nama lengkap, tanggal lahir mentah, jam lahir, dan kota lahir TIDAK PERNAH dikirimkan ke server AI.
  • Teks pertanyaan lanjutan yang Anda ketik secara sukarela diteruskan ke backend proxy kami untuk diproses oleh Google Gemini API guna menghasilkan respons refleksi yang relevan.
  • Server kami tidak menyimpan riwayat percakapan atau data astrologi Anda setelah sesi bacaan selesai dikirimkan.

3. Izin Aplikasi (Permissions)

Aplikasi AstroNusa hanya meminta izin minimal:

  • Akses Internet (android.permission.INTERNET): Digunakan semata-mata untuk menghubungi server AI Coach jika pengguna meminta bacaan online. Seluruh perhitungan bagan, Human Design, PDF, dan Primbon tetap berfungsi 100% secara offline tanpa internet.

4. Kontrol dan Penghapusan Data

Anda memiliki kendali penuh atas data Anda:

  • Anda dapat menghapus seluruh data profil yang tersimpan kapan saja melalui menu Pengaturan > Hapus Profil di dalam aplikasi.
  • Menghapus aplikasi (uninstall) dari perangkat Android Anda akan menghapus seluruh data lokal secara permanen.

5. Lisensi Pustaka Pihak Ketiga

Aplikasi ini menghormati hak cipta dan lisensi sumber terbuka:

  • Swiss Ephemeris (sweph): Digunakan di bawah lisensi GNU AGPL-3.0 dari Astrodienst AG.
  • GeoNames: Basis data koordinat kota Indonesia digunakan di bawah lisensi Creative Commons Attribution 4.0 (CC BY 4.0).
